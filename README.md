NEWCAFE Demo Telegram Bot

Telegram botining demo loyihasi. Banner, mahsulot va aksiya rasmlari assets/ papkasida.

Imkoniyatlar

 ● /start orqali bannerli bosh sahifa
 ● Mahsulotlar katalogi
 ● Savatchaga qo’shish va savatchani ko’rish
 ● Demo buyurtmani tasdiqlash
 ● Aksiya banneri, brend haqida va aloqa bo’limlari

> Bu o’quv namoyishi: haqiqiy to’lov, yetkazib berish yoki ma’lumotlar bazasi yo’q.
> Mahsulot narxlari va aloqa ma’lumotlari namunaviy.

Ishga tushirish

Python 3.10+ kerak.

python -m venv .venv

Windows PowerShell:

.venv\Scripts\activate

pip install -r requirements.txt

$env:BOT_TOKEN=“BOTFATHER_TOKENINGIZ”

python main.py

macOS / Linux:

source .venv/bin/activate

pip install -r requirements.txt

export BOT_TOKEN=“BOTFATHER_TOKENINGIZ”

python main.py

BotFather tokenini hech kimga yubormang va GitHub’ga joylamang.
